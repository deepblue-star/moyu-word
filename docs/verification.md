## 交付范围

开发分支 `develop`。Windows 原生 WPF / C# 5，.NET Framework 4.6+，主程序、安装器、卸载器和 PDFium 均为 x86。支持 Windows 10 32/64 位及 Windows 11 64 位的 WOW64；无需额外语言环境、浏览器内核或运行时下载。

## 数据与边界

- 程序与数据目录分离。收藏、导入和设置在 `%LOCALAPPDATA%\MoyuWord`，升级/卸载保留；卸载只删除安装记录中属于程序的文件。
- PDF 缩放 25%–300%，渲染上限 4096 单边 / 800 万像素，文件最大 128 MiB；加密 PDF 会给出提示。PDF 自身绘制的白色背景仍属于内容，空白纸面为透明。
- 首次启动短暂显示 3 秒，任务栏唤回短暂显示 2 秒，恢复透明度显示 5 秒，之后恢复严格的悬停显示。文件选择对话框打开时暂停隐藏，防止选文件过程中窗口消失。
- 本次测试在错题本留下 `abandon`，并导入 2 词示例词库，方便直接查看。它们属于本机测试状态，不在新安装包的默认个人数据中。
- 专四词库为测试学习数据，上游无明确再分发许可证；商业分发前须取得授权或替换。来源和完整 PDFium 许可见 `third-party`。
